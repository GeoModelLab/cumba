# cumba: Carbon Use Model for Yield and Brix Assessment in Processing Tomato

A daily time-step crop model for processing tomato that simulates
phenology, a three-layer soil-water balance, and fresh-fruit yield and
Brix. Two entry points are provided:
[`cumba_experiment`](https://GeoModelLab.github.io/cumba/reference/cumba_experiment.md),
which replays observed irrigation schedules (for calibration), and
[`cumba_scenario`](https://GeoModelLab.github.io/cumba/reference/cumba_scenario.md),
which schedules deficit irrigation automatically when the crop water
status (1 minus the water stress index) falls below phase-specific
thresholds.
